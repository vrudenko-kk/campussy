# Навигационная карта Финансового университета

Веб-приложение для навигации внутри корпусов Финансового университета. Пользователь выбирает корпус и помещение, видит здание в 3D, переходит на поэтажную карту и получает наглядный маршрут до нужной точки.

## Текущий пилот

Рабочее приложение находится в `dist/`: статический HTML, CSS и JavaScript без обязательного backend. Запуск из корня репозитория: `python3 -m http.server 4173 --directory dist`, затем открыть `http://localhost:4173/`.

В пилоте есть отдельный главный вход и путь через внутренний двор, схемы 1-го и 8-го этажей корпуса 3, сохранённый план 5-го этажа корпуса 1 и демонстрационные схемы других этажей. На мобильном экране этаж открывается целиком; кнопки «+» и «Весь этаж» управляют масштабом. Маршруты используют общую с картой геометрию дверей и проходов.

Проверки: `node --test tests/navigation.test.mjs`. Текущая архитектура и ограничения описаны в `docs/architecture.md`, источники — в `docs/data-sources.md`. План разработки и роли ниже сохраняют исходное видение проекта; безбарьерный режим и серверный API остаются следующими этапами.

## Цель первого этапа

Создать работающий MVP веб-приложения, который позволяет:

- открыть приложение без регистрации;
- выбрать корпус и этаж;
- найти аудиторию или объект инфраструктуры;
- указать начальную и конечную точки;
- построить маршрут по одному этажу и между этажами;
- увидеть маршрут и пошаговые инструкции на карте;
- выбрать доступный маршрут с учётом лифтов и безбарьерных проходов;
- открыть приложение на компьютере или смартфоне.

Инфомат, Face ID, биометрия и персонализированная навигация не входят в первый MVP. Инфомат может стать отдельным этапом после проверки веб-версии на реальных пользователях.

## Основной пользовательский путь

1. Пользователь открывает главный экран с 3D-моделью здания.
2. Выбирает корпус, этаж или выполняет поиск помещения.
3. Указывает точку отправления и пункт назначения.
4. Приложение рассчитывает маршрут.
5. Пользователь видит маршрут на поэтажной карте и пошаговые подсказки.

## Предлагаемая структура репозитория

```text
apps/
  web/          # пользовательский интерфейс
  api/          # серверное API
packages/
  shared/       # общие типы, схемы и утилиты
  map-data/     # тестовые данные корпусов, этажей и маршрутов
docs/           # документация, решения и схемы
infrastructure/ # окружения, контейнеры и развёртывание
```

Структура является стартовой и может быть уточнена командой после выбора технологий.

## Предлагаемый стек

- Frontend: TypeScript, React, Next.js, Three.js или React Three Fiber.
- Backend: Python, FastAPI, PostgreSQL.
- Маршрутизация: граф узлов и рёбер, алгоритм A* или Дейкстры.
- Инфраструктура: Docker, CI/CD, тестовое и рабочее окружения.
- Документация API: OpenAPI.

## Как запустить проект локально

Пилот — статическое веб-приложение: сборка и установка пакетов не нужны. Нужен только Python 3 (на macOS обычно уже установлен).

1. Получите папку проекта: клонируйте репозиторий по выданной вам ссылке или распакуйте архив с проектом.
2. Откройте Terminal и перейдите в папку проекта:

```bash
cd /путь/к/campussy
```

3. Запустите локальный сервер:

```bash
python3 -m http.server 4173 --directory dist
```

4. Откройте в браузере [http://localhost:4173](http://localhost:4173).

Не открывайте `dist/index.html` двойным щелчком: приложению нужен HTTP-сервер, иначе браузер может ограничить загрузку модулей и данных. Чтобы остановить сервер, вернитесь в Terminal и нажмите `Ctrl + C`.

### Как показать друзьям в одной Wi-Fi-сети

Запустите сервер так, чтобы он был доступен устройствам в локальной сети:

```bash
python3 -m http.server 4173 --directory dist --bind 0.0.0.0
```

На Mac узнайте IP-адрес компьютера:

```bash
ipconfig getifaddr en0
```

Отправьте другу адрес вида `http://192.168.x.x:4173` (подставьте полученный IP). Ваш компьютер и телефон/ноутбук друга должны быть подключены к одной Wi-Fi-сети; при первом запуске macOS может попросить разрешить входящие подключения для Python.

Для показа через интернет нужна опубликованная версия с открытым доступом. Текущая ссылка пилота настроена как закрытая, поэтому незарегистрированные пользователи её не увидят.

Архитектура описана в `docs/architecture.md`, источники и ограничения данных — в `docs/data-sources.md`.
